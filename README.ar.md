# تطبيق إدارة المهام (Todo App)

تطبيق بسيط لإدارة المهام اليومية باستخدام Flask و HTML/CSS/JS مع Tailwind CSS.

## المميزات
- إضافة مهام جديدة
- تحديد المهام كمكتملة
- حذف المهام
- حفظ البيانات في قاعدة SQLite محلية (ملف todos.db) فتبقى المهام بعد إعادة التشغيل
- اختبارات آلية: `python -m unittest -v`

## كيفية التشغيل

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح http://127.0.0.1:5000 في المتصفح.

## التقنيات المستخدمة
- Python Flask
- HTML5 + Tailwind CSS
- JavaScript
